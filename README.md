# DermaTape Consulting

피부부착용 의료기기·웨어러블 디바이스·피부부착 패치 기업을 위한
**의료용 테이프 선택 및 적용 컨설팅** 웹사이트의 기본 프레임입니다.

## 무엇을 하나요

고객사가 제품의 착용 조건을 입력하면, 지식 베이스를 기반으로
적합한 **접착제(Adhesive)** 와 **원단(Backing)** 조합을 추천합니다.

## 구성

```
medtape-consult/
├── index.html          # 랜딩 + 진단 + 지식베이스 + 규제 + 문의
├── styles.css          # 청록 메디컬 톤, 반응형
├── app.js              # 렌더링 + 추천 스코어링 엔진 + 폼 처리
├── data/
│   └── knowledge.js    # 접착제/원단/규제 지식 베이스 (window.MEDTAPE_KB)
└── README.md
```

## 실행 방법

정적 사이트이므로 서버 없이 `index.html`을 열어도 되지만,
권장 방식은 로컬 서버입니다.

```bash
cd medtape-consult
python3 -m http.server 8123
# 브라우저에서 http://localhost:8123 접속
```

## 주요 섹션

- **히어로** — 서비스 소개 및 진단 CTA
- **컨설팅 서비스** — 선정 / 적용성·안전성 / 다이컷 설계 / 규제 대응
- **테이프 추천 진단** — 착용기간·피부민감도·방수·활동량·재부착 조건 입력 → 맞춤 추천
- **지식 베이스** — 접착제 5종, 원단 5종의 특성 비교(접착력/피부순함/내습성 등)
- **규제·품질 체크리스트** — ISO 10993, ISO 11607, MDR/K-MDR, ASTM D3330
- **상담 요청** — 문의 폼 (현재 데모: 클라이언트 측 확인 메시지)

## 추천 엔진 요약

`app.js`의 `scoreAdhesive` / `scoreBacking`가 입력 조건별 가중치를 적용해
후보에 점수를 매기고 상위 2개를 추천합니다. 가중 기준:

| 입력 | 반영되는 특성 |
|------|----------------|
| 착용 기간 | 접착제 `wearTime` 적합도, 원단 통기성 |
| 피부 민감도 | 접착제 `skinFriendliness` (신생아일수록 가중 강화) |
| 방수 환경 | 접착제 `moistureResistance`, 원단 `waterproof` |
| 활동량 | 접착제 `adhesionStrength`, 원단 `conformability` |
| 재부착 | 접착제 `repositionable` |

## 커스터마이징 포인트

- **지식 베이스 확장**: `data/knowledge.js`의 배열에 제품/특성 추가
- **자사 제품 라인업 연결**: 각 접착제 항목에 실제 제품 코드 필드를 붙이면 추천 결과에 노출 가능
- **문의 폼 실제 연동**: `bindContactForm`에서 백엔드/이메일 API 호출로 교체
